# 🛒 Quick Cartel
Quick Cartel is an e-commerce platform built using Next.js, Supabase, and Stripe. It allows users to create accounts, browse products (or 'consult articles'), and securely process payments through Stripe.

# 🚀 Getting Started

### Prerequisites

- [Download and Install](https://nodejs.org/fr/download) the required Node's version for your system.
- Develop locally while running the [Supabase stack](https://supabase.com/docs/guides/local-development?queryGroups=package-manager&package-manager=npm) on your machine.

### Tech Stack

- ✅ Laravel
- ✅ Vue js
- ✅ MySql

### Installation

#### Clone & Run the project

```bash
# Clone & Navigate to the project
git clone https://github.com/ElieRu/quick-cartel.git
cd quick-cartel

# Install Dependencies
npm install

# Run
npm run dev
```
